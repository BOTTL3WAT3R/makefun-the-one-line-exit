A one-line resignation letter for The One-Line Exit on make.fun: a fortune
teller resigns, effective immediately, because she has seen next quarter's
numbers and refuses to be the one who has to tell them. Running
`python3 main.py` writes the letter to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
